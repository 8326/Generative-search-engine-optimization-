    What gets checked

    Technical SEO

    HTTP status, HTTPS, canonical, robots directives, viewport, language, robots.txt and sitemap discovery.

    On-page SEO

    Title and meta description length, heading structure, Open Graph tags, structured data and image alt text.

    Content quality

    Word count, readability, repeated or empty headings and how descriptive your link text is.

    Clear fixes

    Every issue has a severity, a reason it matters, and corrected HTML you can copy.

    Transparent score

    Weighted, documented checks. Items that can't be verified are reported separately, never counted as failures.

    Safe fetching

    The server blocks private networks, validates every redirect and limits request size and rate.
